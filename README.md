# Ivan Zhang — personal portfolio

A responsive portfolio based on Ivan's supplied resume. The website is a single `index.html` with embedded CSS and vanilla JavaScript. The original PDF is included for the **Download Resume** button.

## View and edit

Open `index.html` in a web browser. Edit it in VS Code and refresh the browser to see changes. No dependencies or build step are required.

## Included

- Hero, biography, education, research/capstone experience, three featured projects, skills, and contact.
- Responsive navigation, keyboard focus states, reduced-motion support, and printable layout.
- A contact form that opens an email draft. It does not send messages itself.
- A working download of the original resume PDF.

## Publishing on GitHub Pages

In this repository, open **Settings → Pages** and choose **Deploy from a branch**, then select **main** and **/ (root)**. Save. GitHub will display the published URL when deployment completes.

GitHub Pages for a private repository requires a plan that supports it. The repository does not have to be made public to view the local website.
